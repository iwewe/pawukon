# Glosarium

Istilah yang dipakai di dokumentasi ini, urut abjad. Penjelasan lebih panjang ada di [halaman 1](01-apa-itu-weton-dan-pawukon.md) dan
[halaman 3](03-kalender-jawa-dan-kurup.md).

| Istilah | Arti |
|---|---|
| **AJ** | *Anno Javanico*, tahun Jawa. Hari pertama kalender ini adalah 1 Sura 1555 AJ = 8 Juli 1633. |
| **Almanak Jawa** | Kalender cetak berisi tanggal Jawa. Dipakai sebagai pembanding hasil. |
| **Asapon, Aboge, Amiswon, Amahgi** | Nama empat kurup pertama, menurut hari-pasaran 1 Sura tahun Alip. Lihat *Kurup*. |
| **Betaljemur Adammakna** | Kitab primbon yang menjadi sumber tafsir di repositori ini. |
| **Checksum (SHA-256)** | Sidik jari sebuah data. Dipakai di sini untuk memastikan hasil satu implementasi sama persis dengan acuan di setiap hari. |
| **Dina (hari)** | Hari dalam pekan tujuh hari. Juga berarti nomor hari dalam bulan Jawa. |
| **Epoch (titik awal)** | Hari ke-0 dalam hitungan: 8 Juli 1633, Jumat Legi. |
| **Hilal** | Bulan sabit paling awal yang tampak sesudah bulan baru. Pustaka ini tidak memakai pengamatan hilal. |
| **Hisab urfi** | Kalender yang dihitung dengan aturan tetap, bukan dengan pengamatan. Kalender Jawa Sultan Agungan termasuk jenis ini. |
| **Keraton Ngayogyakarta** | Acuan kalender di repositori ini. |
| **Konjungsi** | Saat Bulan dan Matahari segaris dilihat dari Bumi, yaitu bulan baru astronomi. |
| **Kurup** | Siklus 120 tahun; di akhirnya kalender dimundurkan satu hari. Lihat [halaman 3](03-kalender-jawa-dan-kurup.md). |
| **Lambang** | Penanda bergilir tiap windu: Kulawu dan Langkir. |
| **Magrib** | Saat matahari terbenam. Hari Jawa berganti saat magrib. |
| **Neptu** | Angka tiap hari dan pasaran; jumlahnya adalah neptu weton. |
| **Pasaran** | Pekan lima hari: Legi, Pahing, Pon, Wage, Kliwon. |
| **Pawukon** | Siklus 210 hari (30 wuku × 7 hari); juga nama sistemnya. |
| **Petungan** | Tradisi perhitungan hari baik dan watak berdasarkan weton dan angka lain. Tradisi, bukan sains. |
| **Selapan** | Siklus 35 hari: weton yang sama berulang. |
| **Sinodis (bulan)** | Satu putaran Bulan dari bulan baru ke bulan baru, rata-rata 29,53 hari. |
| **Spekulatif** | Penanda hasil sesudah 25 Agustus 2052: aturan diteruskan tanpa acuan yang menetapkannya. |
| **Sultan Agungan** | Kalender Jawa yang dimulai pada tahun 1633 (1555 AJ), memadukan hitungan Jawa dengan bulan-bulan Islam. |
| **Tahun wastu / wuntu** | Tahun 354 hari / 355 hari. Wuntu: Ehe, Dal, Jimakir. |
| **Tahun (Alip, Ehe, Jimawal, Je, Dal, Be, Wawu, Jimakir)** | Delapan nama tahun yang bergilir dalam satu windu. |
| **Vektor uji** | Pasangan masukan dan keluaran yang sudah diketahui benar, dipakai untuk menguji implementasi. Lihat `spec/vektor_uji.json`. |
| **Weton** | Pasangan hari dan pasaran, misalnya Jumat Kliwon. Ada 35 kemungkinan. |
| **Windu** | Delapan tahun Jawa (2.835 hari). Empat nama bergilir: Kuntara, Sangara, Sancaya, Adi. |
| **Wuku** | Satu dari 30 nama pekan tujuh hari (Sinta sampai Watugunung); berganti tiap hari Minggu. |
